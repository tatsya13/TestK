# Куратор — Управление в образовании

Одностраничный веб-чат виртуального помощника куратора академической группы магистратуры по профилю **«Управление в образовании»** РГПУ им. А.И. Герцена.

Проект реализован как статическая HTML-страница: интерфейс, стили и логика ответов находятся в `index.html`.

## Возможности

- выбор курса магистратуры: **1 курс** или **2 курс**;
- приветственный экран с кратким описанием помощника;
- чат-интерфейс с сообщениями пользователя и бота;
- быстрые кнопки для популярных тем;
- встроенная база ответов по ключевым словам;
- адаптивная верстка для мобильных устройств;
- имитация индикатора набора ответа.

## Темы, по которым отвечает помощник

Помощник содержит справочные ответы по основным вопросам студентов:

- расписание занятий;
- практика и документы для практики;
- договоры, приложения, сроки и подписи;
- контакты деканата;
- запись и обращение в деканат;
- учебный процесс, сессия, справки и стипендии;
- контакты куратора;
- правила формулировки вопроса куратору;
- информация о профиле обучения;
- получение шаблонов документов.

## Запуск

### Вариант 1: открыть файл напрямую

Откройте `index.html` в браузере двойным кликом или через контекстное меню.

### Вариант 2: запустить локальный сервер

Если установлен Python 3, выполните команду в корне проекта:

```bash
python3 -m http.server 8000
```

После запуска откройте в браузере:

```text
http://localhost:8000
```

## Использование

1. Откройте приложение в браузере.
2. Выберите курс: **1 курс** или **2 курс**.
3. Нажмите одну из быстрых кнопок или введите вопрос вручную.
4. Получите справочный ответ от помощника.

Примеры вопросов:

- `Расписание занятий`
- `Какие документы нужны для практики?`
- `Контакты деканата`
- `Сессия и экзамены`
- `Как задать вопрос куратору?`

## Настройка ответов

Ответы чат-бота хранятся в объекте `KNOWLEDGE` внутри `index.html`. Чтобы изменить или добавить тему:

1. Найдите объект `KNOWLEDGE` в скрипте.
2. Добавьте новый раздел с массивом `keywords`.
3. Укажите строку ответа или функцию `reply`.

Пример структуры:

```js
'новая_тема': {
    keywords: ['ключевое.*слово', 'вариант вопроса'],
    reply: 'Текст ответа помощника'
}
```

## Ограничения

- Приложение работает полностью на стороне браузера.
- Данные не сохраняются между сессиями.
- Ответы формируются по заранее заданным ключевым словам.
- Помощник не заменяет официальные источники университета и сотрудников деканата.
