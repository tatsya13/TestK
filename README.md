# Чат-бот «Куратор магистратуры»

Небольшой Python-бот для помощи куратору группы магистратуры: отвечает на типовые вопросы студентов о расписании, дедлайнах, документах, контактах, практике и мероприятиях.

## Возможности

- интерактивный CLI-чат на русском языке;
- поиск ответов по ключевым словам и синонимам;
- база знаний в JSON, которую легко редактировать без изменения кода;
- подсказки по доступным темам;
- fallback-ответ с рекомендацией обратиться к куратору, если вопрос не распознан;
- модульные тесты для логики подбора ответов.

## Быстрый старт

Требуется Python 3.10+.

```bash
python -m curator_bot.cli
```

Примеры вопросов:

```text
Какая сегодня консультация?
Когда дедлайн ИПР?
Какие документы нужны для практики?
Контакты куратора
Помощь
```

Для выхода из чата введите `выход`, `exit` или `quit`.

## Настройка базы знаний

Все ответы хранятся в [`curator_bot/knowledge_base.json`](curator_bot/knowledge_base.json). Чтобы добавить новую тему, создайте объект с полями:

- `id` — уникальный идентификатор темы;
- `title` — название темы для меню помощи;
- `keywords` — слова и фразы, по которым бот определяет вопрос;
- `answer` — текст ответа студенту.

После изменения базы знаний запустите тесты:

```bash
python -m pytest
```

Если `pytest` не установлен, можно выполнить базовые проверки стандартным модулем `unittest`:

```bash
python -m unittest discover -s tests
```

